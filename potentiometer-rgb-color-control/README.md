# Potentiometer RGB Color Control

I used a potentiometer to control the color of an RGB LED.

## What I used

* Arduino Uno
* RGB LED
* Potentiometer
* Resistors
* Breadboard
* Jumper wires

## What I learned

* Using `analogRead()`
* Using `analogWrite()`
* Using `map()`
* Controlling RGB LED colors with a potentiometer
